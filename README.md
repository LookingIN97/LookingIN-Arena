# LookingIN Arena

LookingIN Arena is the public, static archive for LookingIN Custom PVP
leaderboards. The site is generated by the private LookingIN source tooling
and published through GitHub Pages.

Each season segment (`sN-h1`, `sN-h2`, `sN-h3`) is published once after it closes.
The site contains permanent TOPS leaderboards, sanitized cropped previews and
the exact authorized share strings displayed in their ranking rows for copying.
Original player-build PNGs, private reports, source paths, build digests, private
simulator code and installable releases must never be published here.

`docs/data/archives.json` is the permanent registry. Leaderboards live under
`docs/patches/<seasonId>/` with their own immutable assets. Repeating the same
publication is a no-op; a different result cannot replace an occupied season.
Steam build IDs are not publication identities. Previously published legacy
pages and their assets are retained under their established paths.

The homepage and `/history/` list every published leaderboard. The old `/latest/`
URL only redirects to this directory. There is no current/final lifecycle and no
mutable "latest" leaderboard. Normal publication only appends a new archive and
updates the directory; all existing archive entries and files stay unchanged.

LookingIN Arena is an unofficial community project and is not affiliated with
or endorsed by Tempo or The Bazaar.

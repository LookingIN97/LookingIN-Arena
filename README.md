# LookingIN Arena

LookingIN Arena is the public, static archive for LookingIN Custom PVP
leaderboards. The site is generated by the private LookingIN source tooling
and published through GitHub Pages.

This repository contains only sanitized Top 10 reports and cropped preview
images. It must never contain original player-build PNG files, authenticated
share codes, source paths, private simulator code, or installable releases.

The current leaderboard is served from `docs/index.html`; finalized historical
leaderboards live under `docs/patches/<steam-build-id>/`.

LookingIN Arena is an unofficial community project and is not affiliated with
or endorsed by Tempo or The Bazaar.
